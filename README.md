# Puzzle Game
A simple 5x5 drag-and-drop puzzle game built with HTML, CSS, and JavaScript. Users can rearrange shuffled image tiles on a board to complete the puzzle.

## Features

5x5 puzzle board

25 draggable image tiles

Drag-and-drop mechanics to swap tiles

Shuffling of tiles using the Fisher-Yates algorithm

Blank tile placeholders for empty spaces

## Tech Stack
- JavaScript
- HTML & CSS
